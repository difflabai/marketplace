# Task Board

## Status Legend

| Status | Meaning |
|---|---|
| submitted | New task, not yet started |
| working | Currently in progress |
| input_required | Blocked, needs human input |
| completed | Done |
| failed | Could not be completed |
| canceled | No longer needed |

## Active Tasks

See `active/` directory for current tasks.

## Completed Tasks

See `completed/` directory for finished tasks.
